# Sojol Karim — Cybersecurity Portfolio

Professional static portfolio site for GitHub Pages.

## Structure

- `index.html` — page structure and content
- `css/style.css` — responsive styling, glassmorphism UI, intro scene, and 3D cube
- `js/main.js` — intro sequence, mobile navigation, cube interaction, and scroll reveals
- `assets/` — future images/icons/assets

## GitHub Pages

This site is a static HTML/CSS/JS project and can be published directly with GitHub Pages.
